# Week 05 Report — Machine Learning for Smart and Connected Systems (ML4SCS)

## Weekly Goal
Complete the four-class dataset, retrain the model on digits 0–3, and prepare the interim presentation on 21 May.

## Work Done This Week

### 1. Data Work
Recorded 10 Phyphox runs each for digits 0, 1 and 2, with accelerometer (without gravity) and gyroscope exported together per run, giving 40 recordings across four classes. Each digit was written by one person, so digit and writer coincided in this first set.

Extended the set afterwards to 30 recordings per digit from three different people, so that a class no longer depended on a single writer, 120 recordings in total.

### 2. Analysis / Modeling Work
Retrained the Random Forest (100 trees, 3-fold cross-validation) on all four classes: 100% cross-validation accuracy on the 40-recording set, and 62% once the extended three-writer set was used.

Added `evaluate.py` for more than a single accuracy number: a classification report per digit, a confusion matrix, and the top 10 of the 24 statistical features by importance. It fits and predicts on the same data there, so the cross-validation score stayed the only out-of-sample number.

Set `predict.py` to digits 0–3 for the live demo and ran it on a new recording folder, one probability per class, with the model stored via `joblib`.

### 3. Repository / Documentation Work
Nothing was pushed to GitHub this week; the new scripts stayed on the local machines, with the data folder hard-coded to one team member's `Downloads` path. Prepared the interim presentation slides.

## Experiments Conducted

| Experiment | Change Made | Result | Interpretation |
|-----------|-------------|--------|----------------|
| Multi-class recording | 10 Phyphox runs each for digits 0, 1, 2 | 40 recordings across four classes | First real multi-class training set |
| Four-class training | Random Forest on digits 0–3 | 100% cross-val accuracy | Expected, digit and writer coincide in this set |
| Extended dataset | 30 recordings per digit from three writers | Accuracy dropped to 62% | Model had learned writing styles, not digits |

## Results
The four-class pipeline ran end to end: Phyphox recording → preprocessing → Random Forest → prediction with probabilities. The 100% on the first set dropped to 62% once three writers were involved. The demo was ready for the presentation on 21 May.

## Challenges
- The first set had one writer per digit, so a score on it would reflect the writer as much as the digit
- The 24 global statistics drop the order of the movement, which is what separates the digits
- Start and stop had to be pressed by hand for every recording, workable in the lab, not in a live demo
- Only 4 of the 10 digits were covered

## Key Insights
- A cross-validation score is only as good as its split: with digit and writer coinciding, the classifier can identify the person rather than the digit
- Adding writers changes the dataset more than adding recordings from the same person
